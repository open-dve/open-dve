# MDIO (Management Data Input/Output) - protocol summary for verification

The station management interface of IEEE 802.3: a two-wire serial bus over
which a station management entity (STA, usually in the MAC/SoC) reads and
writes the management registers of one or more PHYs. Two frame formats
share the wires: **Clause 22** (32 PHYs x 32 registers) and **Clause 45**
(32 ports x 32 MMDs x 65536 registers, indirect addressing).

## 2. Signals and electrical model

| Signal | Driver | Model in odve |
|---|---|---|
| MDC | STA only | `mdc`, generated by the master agent from the system clock (`cfg.mdc_half` clocks low + high); runs only during frames and idle cycles |
| MDIO | STA (preamble, header, write TA/data), PHY (TA[0] + read data) | no tristate: each driver has an output/enable pair - `sta_o/sta_oe` (master agent), `phy_o/phy_oe` (slave agent), `dut_o/dut_oe` (RTL PHY) - resolved in `odve_mdio_if` as `mdio = AND(~oe_i | o_i)`: 1 (pull-up) when nobody drives |

Bus topology: one STA, up to 32 PHYs (R2, R3), all sampling MDIO on the
MDC **rising edge** (R4). The STA changes MDIO so that it is stable around
the rising edge (R3: 10 ns setup and hold); the PHY drives its read data
after the rising edge, valid 0..300 ns later (R3), so the STA samples it at
the next rising edge.

## 3. Frame formats

Clause 22 (R2 slide 8):

| Frame | PRE | ST | OP | PHYAD | REGAD | TA | DATA | IDLE |
|---|---|---|---|---|---|---|---|---|
| Read  | 1...1 (32) | 01 | 10 | AAAAA | RRRRR | Z0 | 16 bits from the PHY | Z |
| Write | 1...1 (32) | 01 | 01 | AAAAA | RRRRR | 10 | 16 bits from the STA | Z |

Clause 45 (R2 slides 10, 12):

| Frame | PRE | ST | OP | PRTAD | DEVAD | TA | DATA | IDLE |
|---|---|---|---|---|---|---|---|---|
| Address | 1...1 | 00 | 00 | PPPPP | EEEEE | 10 | 16-bit register address | Z |
| Write | 1...1 | 00 | 01 | PPPPP | EEEEE | 10 | data | Z |
| Read | 1...1 | 00 | 11 | PPPPP | EEEEE | Z0 | data from the MMD | Z |
| Post-read-increment-address | 1...1 | 00 | 10 | PPPPP | EEEEE | Z0 | data from the MMD, then address + 1 | Z |

Fields are sent MSB first. A Clause 45 access is two frames: an address
frame loads the MMD's address register, a write/read frame then accesses
the register it points to (R2 slide 11); the post-read-increment read
advances it, so a block is read with one address frame.

### Timing diagrams (one character = one MDC period, sampled at the rising edge)

Clause 22 read, PHY at address 1, register 2 (one column group per field, one
digit per MDC period; every value is the one present at the rising edge):

```
field     PRE (32)        ST  OP  PHYAD  REGAD  TA  DATA (16)          IDLE
MDIO      1111...1111     01  10  00001  00010  Z0  D15 D14 ... D1 D0  Z (=1)
sta_oe    1111...1111     11  11  11111  11111  00  000 ...        00  0
phy_oe    0000...0000     00  00  00000  00000  01  111 ...        11  0
```

Clause 22 write: identical header with OP=01, then the STA drives TA=10 and
the 16 data bits (`sta_oe` stays 1, `phy_oe` stays 0).

clock 10 ns, `mdc_half` = 4):

## 4. Addressing

- Clause 22: PHYAD (5 bits) selects the PHY, REGAD (5 bits) the register.
  Registers 0-3 are the standard control, status and PHY identifier 1/2.
- Clause 45: PRTAD (5 bits) selects the port, DEVAD (5 bits) the MMD,
  the 16-bit register address comes from the address frame. In the model
  MMD 1 is PMA/PMD and MMD 3 is PCS (the common assignment; the full DEVAD
  table of R1 was not checked).
- A frame to an address nobody answers is not an error on the wire: a read
  then sees the pull-up (TA[0] = 1, data = FFFF).

## 5. Error and abnormal conditions

| Condition | Effect on the wire | Who detects |
|---|---|---|
| fewer than 32 preamble ones (no preamble suppression) | PHY ignores the frame; a read is not answered | PHY (ignores), monitor `MDIO_PRE` |
| Clause 22 frame with OP 00 or 11 | undefined in Clause 22; the model ignores it | monitor `MDIO_OP` |
| write-type TA other than 10 | the DUT/model ignores the write (DUT design choice) | monitor `MDIO_TA` |
| read TA[1] driven by anyone | contention risk | monitor `MDIO_TA` |
| STA drives during a read's TA[0]/data, or not during a write | contention / undriven bits | monitor `MDIO_DIR`, `MDIO_CONT` |
| PHY drives outside TA[0]+data of a read it answers | contention with the next STA bits | monitor `MDIO_IDLE`, `MDIO_CONT` |
| MDIO changes too close to the MDC rising edge | sampling error | monitor `MDIO_SETUP`/`MDIO_HOLD` |
| no PHY at the address / MMD absent | read returns FFFF | scoreboard (expects no answer) |

## 7. Modelled / not modelled

Modelled:
- Clause 22 read/write; Clause 45 address, write, read, post-read-increment
  (with 16-bit wrap of the address register).
- Explicit per-driver output enables, pull-up resolution, contention check.
- 32-bit preamble requirement on the PHY side (frames with fewer ones are
  followed but ignored), counted as every 1 on MDIO since the previous frame
  (idle cycles count, as a PHY sees them).
- Read turnaround Z0 / write turnaround 10, the PHY driving TA[0] and data
  after the MDC rising edge; non-responding PHYs leaving the line pulled up.
- Several PHYs on one bus (slave agent with several addresses, RTL PHY and
  agent together with `+mdio_slave=multi`).
- Standard registers 0 (control, plain RW), 1 (status, RO), 2/3 (PHY ID, RO);
  per MMD: 0 control, 1 status, 2/3 device ID, 5/6 devices in package (RO
  values), a RW window 0x8000..0x800F.
- Error injection: preamble length, write TA value, Clause 22 undefined OP.

Not modelled:
- Preamble suppression (status register bit 6 is reported as 0, `cfg.pre_min`
  can be lowered for the agent side but the DUT parameter `PRE_MIN` is fixed
  at 32 in the TB).
- Register bit semantics (reset bit 15 self-clearing, auto-negotiation,
  loopback, latching-low link status, ...): register 0 is plain storage and
  status is a constant.
- Clause 22 access to Clause 45 registers through registers 13/14 (R2): 13
  and 14 are plain RW storage here.
- Any special meaning of PHY address 0.
- Electrical behaviour (voltage levels, pull-up value, rise times); MDC
  minimum period and high/low time are not checked (the STA is scaled to
  80 ns).
- MMD numbers other than 1 and 3, the "devices in package" bit for Clause
  22 registers, vendor MMDs 30/31.
